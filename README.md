# Royal Limo - Chauffeur / Limo Booking Platform

Full-stack limousine booking product with a modern **Next.js** frontend and **Node.js/Express** backend.

## Overview
End-to-end booking experience for limo/chauffeur services: browse services, manage bookings, and operate admin workflows backed by MongoDB.

## Key Features
- Customer booking flows and service pages
- Admin-oriented booking/content management
- JWT authentication and validated API requests
- Cloudinary media support
- MongoDB persistence

## Tech Stack

### Frontend (`frontend/`)
- Next.js + React + TypeScript
- Radix UI primitives
- Modern UI component patterns
- React Hook Form

### Backend (`backend/`)
- Node.js + Express
- MongoDB
- JWT / bcrypt auth
- Cloudinary, dotenv, express-validator

## Getting Started

### Backend
```bash
cd backend
npm install
# create .env with MongoDB URI and secrets
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## Security
This repository excludes confidential handover documents and SSH keys. Never commit production secrets, private keys, or `.env` files.
